# 灰原カナ：エピソード候補
更新：2026年10月15日

この資料は設定資料作成後の会話で出た構想を保存するもの。刺傷の過去は採用済みだが、理由の詳細と以下の展開は未確定。本編の確定事項にしない。

## 1. 元カノに刺された理由

### 候補：恋人だけが「ここは私の帰る家だ」と思っていた

カナは恋人に合鍵を渡し、好きなものを冷蔵庫に入れ、眠れない夜には朝まで付き合った。恋人への愛情自体はある。

一方でカナはほかの人間も泊める。ある晩、恋人が帰ると、知らない女性が自分の部屋着を着て、自分のマグカップでお茶を飲んでいる。

「雨、すごかったんで。着替え貸したっす」

恋人には、以前から飲み込んできたものがある。

「じゃあ、私とあの女、何が違うの？」
「そりゃ違うっすよ。あんたは彼女じゃん」

カナは違いを説明できたと思っている。恋人は、共有しているはずの親密さや自分の居場所について何も答えてもらえていないと感じる。

この破綻を背景として刺傷事件に至る案。嫉妬する人物が必ず暴力に出るという設定にはせず、この元カノが暴力を選んだ人物として描く。カナの無神経さと、刺した側の責任を混同しない。

### 講座での語り方

「まあ、彼女の服、勝手に貸したんで」
「それで刺されたんですか？」
「あと、マグカップも」
「品目を増やす話ではありません」

初期案のプリンの台詞と、この部屋着・マグカップの案は併存する候補。刺傷の理由はまだ選ばない。

## 2. 子持ちの元恋人を泊める話

### 短編第一話の候補

深夜、昔付き合っていた女性から「今から、行ってもいい？」と電話が来る。カナは事情を聞かず、いつものように承諾する。

玄関を開けると、女性の後ろに小さな子供がいる。

「……増えてる」
「ごめん」
「いや。布団、足りるかなって」

カナは二人を入れる。灰皿を片づけ、子供に目線を合わせる。子供がピアスを見つめている。

「触る？」
子供が頷く。
「引っ張んないでね。私、そこ、取れる仕様じゃないんで」

母親が久しぶりに笑う。

### 展開の候補：母親が戻らない朝

女性が「ちょっと出てくる」と言い、子供を置いて外出する。カナは普段と同じ感覚で送り出すが、翌朝になっても戻らない。

子供の預け先、着替え、食べられないものなどを知らないカナは、そこで初めて困る。

「ママ、いつ帰る？」
「……何時って言ってた？」
「言ってない」
「そっすか」

自分が待たされるのは平気だった。しかし子供が待っているのを見ると、「まあ、そんなこともあるっす」が出てこない。

恋愛講座に子供を連れてくる。

「灰原さんのお子さんですか？」
「いや、元カノの」
「お母さんは？」
「ちょっと出てるっす」
「いつから？」
「昨日の夜」

先生が出席簿を閉じる。恋愛の授業より先に、事情を確かめる必要がある。

### 未決定事項

- 子供の年齢・名前・性別。
- 母親の現在の境遇、外出の理由、戻れない事情。
- カナがどの時点で誰に助けを求めるか。
- 母親が戻るか、以後の暮らしをどうするか。
- 重い題材を、教室のコメディとどうつなげるか。

母親が戻らない展開は提案段階。「子持ちの女性を泊めた」という魅力を生かす別の展開も検討可能。

## 3. カナを中心にした物語の方向

講座では危険な過去を笑って話す女性。家では、人の出入りが多いのに、本人だけがずっとそこにいる。

他人の忘れ物と、帰ってくるかもしれない人のための場所が残っている。危ない話だけで人物を作らず、相手を覚えていること、頼まれれば助けてしまうこと、自分への被害には鈍いことを日常の場面で描く。

仮タイトル候補：『カナの部屋には、帰らない人の物がある』

講座の群像劇の中の一編にするか、カナを主人公にした独立短編・連作にするかは未定。
