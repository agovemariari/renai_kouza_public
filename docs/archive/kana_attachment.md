# カナが誰かに沼る・独占欲が生まれる案【保留】

更新：2026年10月16日

[設定資料の索引へ](../settings.md)／[現在のカナ設定](../characters/kana.md)

カナが誰かに本気で沼り、帰ってほしくなくなる筋道は、ユーザー判断でいったん保留。以下は旧案の保存であり、採用設定・今後必ず起きる展開として扱わない。現状に不満や空虚さがある人物と決めつけず、現在は今の暮らしをもう少し平和にするために講座を活用する方針を優先する。夏生とのキスは別に採用を維持する。

## 旧案の記録

### 本気になる可能性と、最初の爆発【旧案・保留】

交際人数が三桁に及ぶほど経験豊富、という規模感を候補にする。正確な人数は未確定。夏生への入り口は「まあ可愛いかも」程度でも、こちらを心配し、食事や体調を気にする相手と過ごすうち、自分から連絡を待つようになる可能性がある。

ただし、夏生を最終的な恋愛相手や、カナが本気になる唯一の相手には固定しない。多くの人物と絡める広さを残す。夏生との[復縁と避難の循環案](../characters/natsuki.md)は、カナの気持ちが変わる一つの経路として扱う。

#### 誰でも帰れる家と、この人に帰ってきてほしい家

誰の忘れ物も残しておく女が、ある相手の使ったタオルだけは他人に渡したくなくなる。経験が豊富だからこそ、相手が別の人のもとへ帰る兆候にも気づく。いつもどおり見送れることと、平気であることは別になっていく。

相手が自分の心へ踏み込むほど、去るもの追わずでいられなくなる。ただし当面の爆発は、他人を強制的に引き留める方向へ進めず、自分の拒否と願いを初めて言葉にする程度に留める。

#### 自分のために、家の扉を閉める

誰かが困って来て、事情が片づくと別の相手へ帰る。その繰り返しの中で、自分の家が「誰もカナ本人を選ばなくても成立する場所」になっているのではないかと気づく夜を候補にする。すべての来訪者がカナを利用しているという確定設定にはしない。

「今日は、無理っす」
「……誰か来てんの？」
「いや」
「じゃあ」
「誰もいないです。今日は、誰も泊めたくない」

いつもの帰れる場所が初めて閉まる。カナにとっては、自分の都合で誰かを迎えない選択をする夜。

そこで相手が「分かった。じゃあ、外、出られるか」「お前に会いに来たんだよ。泊まるのは、別でいい」と返せると、カナのほうが動けなくなる。助けや宿のためではなく、カナ本人に会いに来たという言葉。言う役は夏生に固定せず、元恋人や今後の人物も含めて検討する。

#### 自分の「嫌」を差し出す

「私が嫌だって言っても、帰ります？」

事情を知らないから不安なのではなく、分かっていても帰ってほしくない。他人の拒否を受け入れてきた人が、自分の拒否と願いを初めて相手に聞いてもらおうとする。

相手の返事次第で自分が傷つくことを、ひょうひょうと流せなくなる場面にする。他人の選択を奪う展開は現時点では採用せず、拒否を尊重できる長所が試される入口までを描く。具体的な回、相手、結末は未定。



## 夏生側の循環案から保留へ移した部分

カナ側にも「喧嘩しなくても、来ていいんすけど」という望みが生まれ、復縁の反復で次第に帰ってほしくなくなる案。夏生の罪悪感や元カノの嫉妬を描くことから、カナ自身の恋の深まりを自動的に確定しない。
