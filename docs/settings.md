# 恋愛講座、全員再履修 ― 設定資料・索引

更新：2026年10月16日 ／ v0.24（人物別に分割）

人物の詳細は `characters/` の各資料へ分割。ここには作品の方針・講座の前提・人物一覧を置く。関係や場面案の詳細は中心人物の資料へ集約し、相手の資料からリンクする。

## 作品の方向性

原神や既存作品から離れた、現代を舞台にするオリジナルの恋愛群像コメディ。百合を中心にしつつ、過去の交際相手には男女ともにいる。

「重すぎる女たちが健全な恋愛を学ぶ教室」が舞台。かわいらしい失敗談で終わらせず、読者が「こいつらマジでどうしようもねぇ」と笑ってしまう程度まで振り切る。

笑いの中心は、本人たちの真剣さと判断のずれ。学んだ内容を自分の執着に都合よく適用し、知識が増えるほど事態が悪化する。講座の言葉だけは正しいので、先生も否定に苦労する。

受講生は執着が重い人に限らず、恋愛や共同生活で「どうしようもない」問題を起こす人も含む。普段の仕事や生活では有能な人物が多い。他人の恋愛には正気のツッコミを入れられるのに、自分のことになると理屈が暴走する。ときどき切なさや魅力が見えるが、それで全員をきれいに更生させない。

### シリーズで絶対に維持するテイスト【ユーザー指定】

「こいつらマジでどうしようもねぇな（笑）」というテイストを壊さず続ける。講座を受けて理解・反省したことと、実際の相手を前に行動を変えられることは別。早々に更生・解決させない。

いつもの修羅場と、相手を沼らせる具体的な親密さを描く。しおりと読者が問題を見抜きながらも「自分もそうされたら弱い」と分かってしまう場面を重ねる。「さっきの講座の意味ないやん！？」というツッコミは、主にしおりの内心で行う。

あくまでコメディ。「かわいそうで見ていられない」ほど苦痛を掘り下げず、「そこで甘やかすんかい！」「その理屈はおかしい」と笑える温度を守る。巻き込まれる側にも、怒る力・言い返す力・その場を引っくり返す力を持たせる。優しさや可愛さを描いても、問題を解決したことにはしない。

シリーズ名：『恋愛講座、全員再履修』【確定】
旧仮題：『恋愛講座に来る女、だいたい手遅れ』。舞台の地域は未確定。講座名は『心地よい距離を育てる、恋愛コミュニケーション講座』。

先生が説くのは、近づくことや遠ざかることを一律に正解とせず、お互いにとって心地よい距離を見つけること。複数の人を好きでいること自体を誤りにせず、それぞれの望みと向き合って関係を探す。先生自身の大量の恋人と線引きの下手さは、騒動の源である一方、透子に希望を与える実例でもある。

## 設定の扱い

- 「採用済みの核」：ユーザーが明確に希望した特徴。カナの存在・外見・恋愛遍歴・危険な生活圏、まひると同居相手の関係、透子と後輩・つよつよお姉さんの三角関係、しおりと近所の妹分の恋愛関係、しおりのムッツリな性格とオチをつける役割、夏生の性格とカナに惹かれる関係、先生の経歴・複数の恋人・お迎え騒動など。
- 「仮設定」：これまで提案した名前、年齢、職業、人物関係。執筆時に変更できる。明示的に確定した結衣・冴子・怜奈・紗月の名前などは各資料の記載を優先する。
- 「保留」：現時点の主要人物・採用設定から外して保存する案。再採用するまでは本編の前提にしない。
- 「追加候補」：カナの魅力を深めるためのアイデア。採用済みの核とは分けて記録する。
- 台詞と場面は口調・笑いのサンプルであり、すべてを本編に入れる必要はない。

## 講座の舞台【仮設定】

資格を持つ独立カウンセラーが、自身の相談業務の一環として主催する恋愛講座。対象は「女性を好きな女性」。女性同士の恋愛コミュニティなどを通じて参加者を募集する少人数の対面講座で、交際中の悩みがある人も、これから恋愛をしたい人も参加できる。レズビアン限定とはせず、男女どちらとの交際歴もあるカナも自然に参加できる。先生は元・大学の学生相談室カウンセラー。相談への親身さと恋愛の線引きができず、複数の成人相談者との交際が問題になって退職している。先生本人も問題を抱えながら教える。詳細は[柳瀬紗月](characters/satsuki.md)。

自治体の市民講座や代講スタッフという初期案は保留。旧案の高瀬真紀とは別の新設定として扱う。先生の名前は柳瀬紗月（やなせ・さつき）に確定。年齢は未定。以降の場面例の「先生」は原則としてこの人物を指すが、保留中の旧筋は自動的に再採用しない。

恋愛の距離感やコミュニケーションを学ぶはずだったが、受講生の問題が毎週想定を超える。教室内で新しい恋愛が生まれ、講座そのものが騒動の発生源になる。

### 授業をめぐる騒動の候補

以下は初期のネタ集。復縁互助会や施設運営への介入など、保留人物に結びつく展開は[保留案](archive/initial_cast.md)の状態に従う。

- 「まず自分を変える」→恋人の上司になれるよう転職する。
- 「相手の拒否を尊重する」→「顔を見せるな」と言われたので着ぐるみで会いに来る。
- 「恋人以外とのつながりを持つ」→受講生同士で復縁互助会を作る。
- 「気持ちを率直に伝える」→復縁を手伝っていた受講生が、依頼人の元カノと交際を始める。
- 講座を存続させるため、先生を好きになった受講生が施設運営に入り込む。
