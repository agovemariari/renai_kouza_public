# 朝倉結衣（あさくら・ゆい）

更新：2026年10月16日

[設定資料の索引へ](../settings.md)

関連：[透子](toko.md)／[冴子](saeko.md)

## 基本設定【名前確定】

成人女性。透子の後輩。年齢・職種は未定。透子を「先輩」と呼び、透子からは「結衣」と呼ばれる。

## 恋愛の核

透子を本気で好き。求めればハグやキスは受け入れられるが、恋人にはなってもらえない。離れようとしても優しく呼び戻され、期待が途切れない。

冴子だけが透子の余裕を奪えることに嫉妬する。一方、自分が透子の帰る場所であることを使い、「待っています。あの人にも、そう伝えてください」と自分の位置を主張するようになる。泣いて待つだけの人物にはしない。透子との同居は未確定。

## 透子の筋道との関わり

透子は結衣の幸せを願うという説明の陰で、自分も結衣がいないと耐えられないと気づいていく。ただし、その気づきだけで結衣の望む関係が成立するわけではない。結衣にも望みと選ぶ力がある。

三角関係の場面案と透子の筋道は[透子の設定](toko.md)に集約する。
