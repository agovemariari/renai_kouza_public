# 桐生冴子（きりゅう・さえこ）

## 基本設定【名前確定】

成人女性。つよつよお姉さん。年齢・職業、透子との出会い方や正式な関係は未定。透子からは「冴子さん」と呼ばれる。「透子」と呼ぶだけで相手の姿勢や声が変わる。

## 恋愛の核

透子を詰めて余裕を奪える女性。ただし、透子はその叱責に喜んでしまい、肝心な話が進まない。

結衣へ与えられている日常の親密さと安心感には嫉妬する。透子を見抜く力があっても、関係の外にいる無欲な助言者にはしない。

## 透子に気づかせる役割【採用する方向性】

透子が「結衣には私以外の幸せを」と語るとき、「結衣があなたなしで大丈夫になったら、困るのはあなたでしょう」とため息交じりに指摘する。透子はようやく自分も結衣を必要としているのかもしれないと気づく。

この指摘によって結衣と透子を結びつけ、自分は身を引くという着地には固定しない。冴子への気持ちも本物であり、冴子自身にも透子といたい望みがある。三人の距離を探す筋道と場面案は[透子の設定](toko.md)を参照。
