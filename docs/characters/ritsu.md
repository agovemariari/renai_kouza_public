# 一ノ瀬律

更新：2026年10月16日

[設定資料の索引へ](../settings.md)

試験的な採用。名前・年齢は仮設定。

## 採用する核

十年間、一人の女性だけを好きでいる。相手には恋人がいる。

講座で出会った女性たちに、自分の好きな人の恋人を引き受けてもらおうとする。

「私は十年間、一人の女性だけを愛しています」
「素敵ですね」
「その人の恋人を、皆さんの誰かに引き受けていただきたいんです」

愛情は一途だが、成就させる手段が破綻している。自分の恋人ではない人の交際を、勝手に組み替えようとする人物。

ユーザーはこの発想を採用。ただし現時点で「出オチで終わりそう」という懸念があり、継続して面白く動かせるかを検討する。主要人物としての役割を完成扱いにしない。

## 人物像【仮設定】

仮名は一ノ瀬律、33歳。職業未定。関係者は成人女性として構想する。

几帳面で物腰が柔らかい。好きな相手に恋人ができたときも祝福し、困らせる告白や嫌がらせはしてこなかった。

十年目に「私が好きでいるだけでは、状況は変わらない」と気づく。しかし自分が相手と向き合うより先に、周囲を動かして交際の空席を作ろうとする。

## 講座で見つけてしまう可能性【場面候補】

受講生たちの話を聞き、先生を見る目と生徒を見る目が変わる。

「この人たちは恋愛が下手なのではない。私にはできないことが、できる人たちだ」

カナに相談する。

「お付き合いしている方がいる女性でも、お好きになることはありますか？」
「まあ、ありますね」
「よかった」

見せる写真は、自分が好きな女性ではなく、その女性の恋人。

「この人が好きなんすか？」
「いいえ」
「じゃあ、何で？」
「この方に、別の幸せを見つけていただければと思って」

先生が戻ってくる。

「一ノ瀬さん。今、何の相談を？」
「人と人を、おつなぎできないかと」
「写真をしまってください」

## 本人の善意と計画の欠陥

誰も不幸にしない計画だと思っている。誘惑して捨ててほしいのではなく、好きな人の恋人にも、新しい相手と幸せになってほしいと願っている。

「あの方には、新しい恋人ができます」
「はい」
「私の好きな人には、私がいます」
「まだ、あなたを選んでいません」
「そこは私が頑張ります」
「そこから頑張ってください」

交際中の二人の意思と、自分が選ばれない可能性が、計画から抜けている。

## カナとの関係【未確定の場面候補】

カナが写真を見て「あ。この人、元カノっす」と言う案。

律は撤退せず、初めて前のめりになる。

「……詳しく伺っても？」

さらに、カナがその二人の過去の揉め事を知っており、「今の恋人と付き合って、やっと落ち着いた」と説明する案もある。

律は好きな女性の穏やかな面しか知らず、驚く。しかし最後に出す答えは、

「では、円満に別れていただく方法から考えます」

新情報を、撤退ではなく計画の修正に使う。

以上は会話で出たネタであり、カナの元カノとの関係、吊るされた事件、冷蔵庫の破損などを一つの確定した過去にまとめない。カナがあらゆる人物の元恋人だと便利になりすぎるため、使うつながりは選ぶ。

## 出オチで終わる懸念と今後の検討

現時点の強みは、最初の相談の意外さ。「好きな人の恋人を誰かに引き受けてもらう」という説明を繰り返すだけでは、以後の場面が同じになる。

以下は今後考える論点であり、解決済みの設定ではない。

- 好きな人と実際に会ったとき、律自身はどのように振る舞うのか。
- 十年間の関係と、相手が律をどう見ているか。
- 計画が進む、失敗する、不要になる場面で、何を選ぶ人物なのか。
- 他人の交際を動かそうとする一方、自分の告白を避ける理由は何か。
- カナ以外の受講生と、どのような利害や対立が生まれるか。
- 長く登場させるか、短い一編の中心人物として使うか。
- 職業・日常・口調など、計画以外の人物像をどう作るか。

現時点では試験的な採用として保存し、継続登場の可否は実際の場面を作って判断する。
