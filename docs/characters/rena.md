# 鷹宮怜奈

更新：2026年10月16日

[設定資料の索引へ](../settings.md)

名前確定。関連：[まひると二人の生活・場面案](mahiru.md)／[透子](toko.md)

まひるの同居相手。まひるからは「れなちゃん」と呼ばれ、初対面では「鷹宮です」と名乗る。名前の端正な印象と、まひるの親しい呼び方の落差を生かす。

成人女性。実家が裕福で、まひるの生活を支えられる。まひるとはセフレ関係だが、本人は恋愛感情を持っている。

まひるの風俗通いに傷つく一方、まひるがそばにいることを強く望む。自立してほしいつもりなのに、まひるがバイトを増やそうとすると引き留める。

「そんなに働いたら疲れちゃうよ」
「でも、お金……」
「私と一緒にご飯を食べてくれるほうが嬉しいな」
「そっかぁ。じゃあ、そうする」

自分の世話焼きが相手の依存を保っているという自覚は薄い。まひるだけを矯正すれば解決する関係ではない。

ただしまひるに一方的に丸め込まれるだけの被害役にはしない。甘やかすことと納得したことを分け、まひるの話題転換も見抜いて打ち返す。「チーズも入れる」には「入れて。話は別」と答えられる。愛情はあり、襟は直すし食事も楽しむが、「まだ許してない」と言える。まひるも黙って傷つけるだけでなく、妙な提案を繰り出して打ち返される。

「嬉しくなった自分にも傷つく」など、苦痛へ深く沈む方向には寄せない。二人が一緒にご飯を食べる場面は、安心して笑って見られる関係を目指す。

氏名は鷹宮怜奈に確定。年齢・職業、実家の背景、同居の始まり、生活費の具体的な分担、独占や風俗通いについて交わした約束の詳細は未定。

第二話で、二人は「付き合おう」と話していないことをまひるが明かす。関係の呼び名に迷った末、「あ、せふれ！」と嬉しそうに答える。同居相手はまひるを好きだと伝えており、まひるも「大好き」と答えるが、交際の認識はすり合っていない。「セフレ」はまひる側の命名で、相手もその呼称に同意しているとは確定しない。

まひるの世話をすることは、自分だけの日常の親密さだと思っている。透子が自然にそこへ入ってくると、身体の関係とは別のところで嫉妬する。第二話では二人は鉢合わせていない。
