# 夏生の元カノ（名前未定）

更新：2026年10月16日

[設定資料の索引へ](../settings.md)

成人女性。関連：[夏生](natsuki.md)／[カナ](kana.md)

名前未定の成人女性。普段は落ち着いており、夏生が別れを切り出しても追わない。

「もういい。別れる」
「うん。鍵、置いていってね」

しかし、夏生がまた自分を選んで告白しに来ることを、少し楽しみにしている。振り回されるだけの被害役ではなく、復縁の慣習に自分も甘えている。

「まだ好きだ。もう一回、付き合ってくれ」
「どのくらい？」
「……何が」
「私のこと、どのくらい好き？」

真っ赤でも目を逸らさず、自分の気持ちを言う夏生が毎回ちゃんと可愛い。夏生の好意は本物なので、こちらも本気で付き合い直す。

夏生の告白例：
「飯食ってても、お前これ好きだったなって思うし。帰っても誰もいねぇの、腹立つし。……会いたかった」

復縁後、夏生がソファで待っている場面案：
「先に寝ててよかったのに」
「……一緒に寝たいから、待ってた」

ただし元カノには、好きだと確かめたいあまり、わざと一言多くなる悪癖がある。

「私がいなくても、平気だった？」
「平気じゃねぇから来たんだろ」
「でも、別れるって言ったのは夏生だよ」
「……だから、悪かったって」
「今度は、何日くらいもつかな」

しおりの内心候補：
「お客様。その最後の一言、交際期間を削っております」

夏生は怒ると関係を切り、元カノは安心すると夏生をつつく。仲直りの熱量が高いため、喧嘩になる癖を後回しにする。

七回目だけ夏生が来ないと、元カノから連絡する。

「最近、忙しい？」
「別に」
「……今回、長くない？」

破局に、いつもの所要日数がある。

## 今後の登場

七回目の告白を待つ間にカナの存在に焦り、のちに自分から気持ちを伝えられるようになるため受講する。荷物の引き取り、キスをめぐる会話、登場順序は[夏生の設定](natsuki.md)に集約する。結末・名前・年齢・職業は未定。
